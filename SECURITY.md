# Security and privacy

Do not open a public issue containing a token, credential, private URL, local path, device name, IP address, session identifier, raw log, or unredacted screenshot.

For a sensitive report, use GitHub's private vulnerability reporting feature when it is available. Otherwise, provide only a non-sensitive summary and wait for the maintainer to establish a private channel.

If a secret was committed, revoke or rotate it first. Deleting it from the latest file does not remove it from Git history.
