# Contributing

Small, reproducible improvements are welcome.

1. Remove account, device, network, session, path, and secret information from examples.
2. State the OpenClaw version and node platform when behavior may be version-specific.
3. Add or update a JSON example for every sequence-rule change.
4. Run the repository and sequence validators.
5. Explain observed results separately from assumptions.

Do not submit full local configuration files, raw logs, private screenshots, tokens, or third-party assets.
